# トラブルシューティング

[English](troubleshooting.md) | [简体中文](troubleshooting.zh-CN.md) | **日本語**

## SteamVR がドライバーを認識しない

次を実行します。

```powershell
.\scripts\register_driver.ps1
```

`%LOCALAPPDATA%\openvr\openvrpaths.vrpath` の `external_drivers` に、ステージング先の `build\out\anyadance` パスが含まれていることを確認してください。登録を変更した後は SteamVR を再起動します。

## 仮想 HMD が表示されない

登録スクリプトを再実行して、完全仮想モードの設定も適用します。

```powershell
.\scripts\register_driver.ps1
.\scripts\restart_steamvr.ps1
```

起動前に物理 HMD を切断し、AnyaDance の仮想 HMD がアクティブな HMD になるようにしてください。

## 表示がぼやける、または不鮮明

仮想 HMD の既定のレンダー解像度は片目あたり `1920x1080` です。画像が柔らかく、またはぼやけて見える場合は、片目あたりのレンダー解像度を上げてください。`steamvr.vrsettings` の `driver_anyadance` セクションを編集し、`headset_render_width` と `headset_render_height` を大きな値（たとえば 4K なら `3840x2160`）に設定して、SteamVR を再起動します。README の HMD レンダー解像度の節と[デバイスモデル](device-model.ja.md)を参照してください。

> **注意：** 片目あたりのレンダー解像度を上げると、GPU 負荷が大幅に増加します。ヘッドセットは左右の目を個別に描画する（実質的に 2 画面を描画する）ため、増加分は両方の目に適用されます。4K（`3840x2160`）は 1080p の約 4 倍のピクセル数で、その負荷が両目それぞれにかかります。どのアスペクト比も使用できます。投影は設定したレンダー解像度に適応するため、画像が引き伸ばされることはありません。

## コントローラーまたはトラッカーが動かない

コントローラーとトラッカーはパケットが停止しても接続済みかつ有効な状態を維持します。動かない場合は `AnyaDance.exe` を起動し、6 台すべてのデバイスを含むフレームが 60 Hz でストリーミングされていることを確認してください。

## UI を閉じると HMD がグレーになる

仮想 HMD が有効な場合、ドライバーはパケットが停止しても HMD を接続済みかつ有効な状態に保ちます。SteamVR のログで `[anyadance]` メッセージを確認し、現在のビルド出力にある `driver_anyadance.dll` が読み込まれていることを確認してください。

## キー操作が効かない

UI はウィンドウがフォーカスされている間だけキーボード状態を読み取ります。また、ImGui のテキスト編集ウィジェットがアクティブな間はキーマッピングが無効になります。UI ウィンドウをクリックしてから、もう一度試してください。

## SteamVR の設定が正しくない

登録スクリプトは設定を次の場所へバックアップします。

```text
%LOCALAPPDATA%\AnyaDance\steamvr.vrsettings.backup
```

`unregister_driver.ps1` はこのバックアップを復元してから、バックアップファイルを削除します。手動で復元する場合は、まずバックアップの内容を確認してから元の場所へコピーしてください。`steamvr.vrsettings` を変更した後は SteamVR を再起動します。

## パケットが無視される

次の点を確認してください。

- `version` が `1` である
- データグラムが 8192 バイト未満である
- デバイス ID が認識対象の 6 つの ID のいずれかである
- デバイスに必要なフィールドがすべて存在する
- 位置の値が有限で ±30 m の範囲内にあり、Y は HMD では 0–25 m、それ以外の 5 台では -30–25 m の範囲内にある
- クォータニオンの順序が XYZW で、長さの 2 乗が 0.5～1.5 の範囲内にある
